경험을 콘텐츠로 바꾸고,
브랜드의 이야기를 만듭니다

브랜드와 콘텐츠를 중심으로 공부하는 경영정보학부 학생이에요. 읽기만 하는 소개가 아니라, 직접 눌러보며 제 생각과 작업을 탐색할 수 있게 만들었어요.

작업 탐색하기 어떤 마케터인지 보기

소개

관심사를 눌러서 제가 어떤 마케터를 지향하는지 확인해 보세요.

브랜드는 로고가 아니라 사람들이 기억하는 인상이라고 생각해요. 왜 그 브랜드를 고르는지, 어떤 순간에 떠올리는지를 관찰하면서 일관된 메시지를 쌓아가는 과정에 관심이 많습니다.

좋은 콘텐츠는 정보를 전달하는 걸 넘어, 보는 사람의 하루에 작은 변화를 줘요. 직접 만들어 보고 반응을 관찰하면서, 읽는 사람 입장에서 다듬는 연습을 하고 있어요.

결국 마케팅의 중심은 고객이라고 믿어요. 제가 겪은 경험과 사용자의 행동을 바탕으로, 사람들이 진짜로 원하는 것을 이해하는 고객 중심 마케터가 되고 싶습니다.

기록

각 단계를 눌러 자세한 이야기를 펼쳐 보세요.

  1. HTML, CSS, JavaScript로 직접 만들어 보고 GitHub Pages에 올렸어요. 처음으로 "만든 것을 세상에 공개"해 본 경험이었습니다.
  2. 나를 어떻게 소개할지 고민하며 구조와 메시지를 정리했어요. 보는 사람 중심으로 생각하는 연습이 됐습니다.
  3. 읽기만 하는 페이지에서, 눌러보며 탐색하는 페이지로 바꿨어요. 사용자의 행동을 끌어내는 것이 콘텐츠의 힘이라고 느꼈습니다.
  4. 실제 브랜드나 제품을 하나 정해, 고객 입장에서 콘텐츠를 기획하고 반응을 관찰하는 작은 프로젝트를 해보려고 해요.

생각

스스로에게 던지는 질문이에요. 눌러서 답을 확인해 보세요.

어떤 마케터가 되고 싶나요?

경험을 바탕으로 고객을 깊이 이해하고, 브랜드의 이야기를 콘텐츠로 풀어내는 마케터가 되고 싶어요.

왜 브랜드와 콘텐츠인가요?

사람의 마음에 오래 남는 건 광고 한 편이 아니라, 꾸준히 쌓인 인상과 이야기라고 믿기 때문이에요.

요즘 가장 집중하는 건?

직접 만들고, 사람들의 반응을 관찰하고, 그걸 바탕으로 다시 다듬는 과정을 반복하는 거예요.
